# 🔥 Smoke House

Uma landing page responsiva para uma hamburgueria artesanal fictícia, desenvolvida com foco em uma identidade visual moderna e inspirada em fogo, brasa e sabores defumados.

O projeto apresenta cardápio, ofertas, informações sobre a hamburgueria, avaliações de clientes e uma interface totalmente responsiva.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- jQuery (via CDN)
- ScrollReveal (via CDN)
- Font Awesome (via CDN)
- Google Fonts (via CDN)

## ✨ Funcionalidades

- Layout responsivo
- Menu mobile (menu hambúrguer)
- Navegação suave entre seções
- Header dinâmico durante o scroll
- Animações de entrada utilizando ScrollReveal
- Destaque automático da seção atual na navbar (scrollspy)
- Cards de produtos com botão de adicionar (feedback visual)

## 🚀 Como executar

Basta abrir o arquivo `index.html` no navegador. Todas as bibliotecas externas (jQuery, ScrollReveal, Font Awesome e Google Fonts) são carregadas via CDN.

Se preferir rodar um servidor local simples (opcional), use um servidor estático de sua escolha. Exemplo com `npx serve`:

```bash
npx serve .
```
